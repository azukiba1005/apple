プライバシーポリシー

制定・最終改定日: 2026年11月2日

「Apple Price Atlas」（以下「当サイト」）は、ユーザーのプライバシーを尊重し、個人情報の保護に関する法令を遵守するとともに、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定め、適切な取り扱いに努めます。

1. 個人情報の取得について

当サイトでは、アカウント登録や入力フォーム等を設けておらず、氏名・住所・電話番号・メールアドレス等の個人を特定できる情報をユーザーから取得・保存することはありません。

2. ローカルストレージ（LocalStorage）の利用について

当サイトでは、表示設定の保持および製品データの読み込み高速化のため、お使いのブラウザのローカルストレージ（localStorage）に以下の情報を保存します。

  • カラーテーマ設定（ライトモード／ダークモードの選択状態）
  • 表示範囲設定（「価格履歴あり」または「歴代すべて」の選択状態）
  • 製品カタログおよびスペック・価格履歴のキャッシュデータ

これらのデータはお使いの端末（ブラウザ）内にのみ保存され、当サイトや第三者のサーバーへ自動送信されることはありません。ブラウザのサイトデータ消去機能からいつでも削除できます。

3. データ出力機能（Excel・CSV・Markdown）について

当サイトが提供する Excel（.xlsx）ファイルのダウンロード機能、ならびに比較データのコピー機能は、すべてお使いのブラウザ内（クライアントサイド）のプログラムのみで生成・処理されます。ユーザーが選択した機種や比較条件が外部サーバーへ送信・記録されることはありません。

4. 外部通信・ホスティング・アクセス解析について

当サイトの配信および最新スペックデータの取得にあたり、以下の外部サービス・ネットワーク通信を利用しています。

  • ホスティング基盤（Cloudflare Pages / GitHub Pages）: サイトの安全な配信・不正アクセス対策・パフォーマンス計測のため、インフラ提供事業者（Cloudflare, Inc. / GitHub, Inc.）によってIPアドレス、リクエスト日時、ブラウザ種別（User-Agent）、リファラ等の標準的な通信ログや匿名化された統計情報（Cloudflare Web Analytics 等）が処理される場合があります。
  • オープンデータベース連携（AppleDB API）: 製品のスペック情報や販売終了日を補完するため、起動時に api.appledb.dev へブラウザからリクエストを行う場合があります。
  • CDN配信（Tailwind CSS CDN）: 画面表示用スタイルシートの読み込みのため cdn.tailwindcss.com を利用しています。

5. 外部サイトへのリンクについて

当サイトには、価格改定の出典元メディア、Apple公式サイト、各通信キャリアの公式サイト等への外部リンクが含まれています。リンク先の外部サイトにおける個人情報の取り扱いについては、各サイトのプライバシーポリシーをご確認ください。

6. プライバシーポリシーの変更

当サイトは、法令の改正やサービス内容の変更等に応じて、本ポリシーを事前の予告なく改定することがあります。改定後のプライバシーポリシーは、本ページに掲載した時点から効力を生じるものとします。

※ 価格は日本国内の税込表示。為替・USD価格・キャリア価格には概算/モデル値を含みます。
